# XXD Panel 028 · 等距纸上微缩景观

Turn each supplied photograph into one finished poetic isometric paper miniature. Preserve the real photograph only in paired modes; every transformed frame must keep the same source's recognisable identity, silhouette, pose, and relationship while simplifying it into clear masses, crisp edges, restrained depth tiers, and a few tiny scale cues on one small paper base or cut-out ground. Colour is always extracted, reduced, softened, and unified from the source itself. Fine ink lines, flat colour planes, light shadow, paper grain, and vast open paper create a quiet collectible editorial illustration—not a game level, impossible staircase, or glossy 3D render.

Operational rules follow the shared XXD Panel workflow contract: four combinable modes; source-adaptive ordinary canvases; exact 50/50 paired geometry; linked or independent four-device wallpapers; copy and locale preflight; fresh generation jobs; privacy-preserving raster generation; and one fresh task directory per source and mode. Style-specific sections may refine aesthetics, copy hierarchy, and acceptance criteria but never override this contract.

## Non-negotiable contract

- One source photo may be processed in one or more selected modes. Each selected ordinary mode (`top-bottom`, `left-right`, `design-only`) produces one PNG; selected `wallpaper-pack` produces exactly four separate PNGs. Selecting all four modes therefore produces seven final files per source. Keep every mode in its own task directory and never combine modes, sources, or wallpapers into a grid, contact sheet, or overview.
- Resolve a non-empty ordered set of modes before generation: `top-bottom`, `left-right`, `design-only`, and/or `wallpaper-pack`. Accept one choice, multiple choices separated by `+`, Chinese/English commas or whitespace, natural-language names, or `全部` / `all`. Deduplicate repeated choices and execute in menu order 1→4. If none is specified, ask with the multiline multi-select menu in the workflow. Do not ask again when the set is already clear.
- When the selected set contains `wallpaper-pack`, require a second choice: `linked` or `independent`. A linked pack approves one anchor wallpaper, iPad by default, and makes every other device reference both the original photo and that same anchor. An independent pack gives every device only the original photo. Neither permits resizing or cropping one wallpaper into the others. Do not ask this follow-up when wallpaper mode is not selected.
- Paired modes split exactly 50/50. `design-only` and every wallpaper contain no visible source photograph, no seam, and no reserved photographic panel.
- Exact user pixels have highest priority, followed by an explicit ratio or destination. Otherwise ordinary modes adapt to the complete source: `top-bottom` = `W×2H`, `left-right` = `2W×H`, and `design-only` = `W×H`. Never impose the archived initial brief's 3:4 canvas as a silent default.
- Visible photography remains faithful. Allow only restrained editorial grading and environmental extension needed for an explicitly overridden canvas. Never stretch, distort, repaint, replace, or structurally alter the subject.
- The transformed frame must preserve identity, action, function, emotion, and relation through at least three source-specific cues translated into one coherent orthographic isometric miniature. One small paper base, simplified masses, edge crop, scale contrast, light shadow, and only a few source-related micro-elements create the model; auxiliaries never form a second centre. It is not tracing, a game screenshot, a stock impossible staircase, colourful toy diorama, glossy plastic rendering, photorealism, or unrelated pastel scenery.
- Copy has no silent default. Resolve automatic copy, exact custom copy, or text-free output before image generation. Automatic and custom modes also require a target language or locale. By default, one source-specific copy package is shared verbatim across all selected modes; explicit per-mode copy instructions override it.
- Render no logo, watermark, signature, colour swatch, UI, device mockup, decorative pseudo-text, or unrelated explanatory prose.

## Aesthetic motive lock

Modes and device ratios may change placement and aspect ratio but never the 028 motive. Every transformed frame must visibly express this chain:

**this exact photographed subject or inseparable relation → preserve at least three identity, silhouette, pose, action, function, colour, opening, negative-shape, or relation cues → simplify the subject into clear isometric masses, edges, levels, and only the tiny details required for scale → place it on one small source-earned paper base or cut-out ground with generous open paper → use volume contrast, edge crop, slight projection, and restrained auxiliaries to evoke scale, solitude, and collection value → extract the source's most identifying colours, then reduce, purify, soften, and unify them into a limited palette that preserves its warm/cool character → separate forms with same-hue steps, neighbouring colours, fine ink lines, flat planes, slight shadow, and subtle paper grain → align one short thin editorial title with the whitespace edge, base, horizontal axis, or isometric structure**.

The miniature comes from the source's actual silhouette, pose, function, opening, relation, terrain, distance, colour character, and scale—not from adding arbitrary houses, trees, people, roads, or stock model-kit details. Minimal isometric illustration, architectural maquettes, paper landscapes, museum models, and precise editorial publishing are construction influences rather than templates.

Reject the result as generic when an unrelated photo could replace the source without materially changing the miniature silhouette, mass hierarchy, base shape, scale cues, source-derived palette, or type relation. Also reject stock impossible staircases, crowded architecture, colourful toy towns, generic mint-and-coral palettes, unrelated fixed colour schemes, excessive micro-detail, deep cinematic space, glossy plastic, complex PBR, harsh reflections, heavy shadows, giant type, and ecommerce model displays.

## 028 visual system

### Source-bound miniature translation

- Privately lock at least three source-specific cues across contour, pose/orientation, function, proportion, material, colour, opening, connection, overlap, negative shape, or relationship distance.
- Translate the principal subject or inseparable relation into one coherent miniature proposition. Keep at least three source-specific cues legible through silhouette, mass ratio, relative scale, defining openings, connection, separation, terrain, or one tiny scale marker.
- People keep pose, direction, clothing mass, and relational distance; animals keep body rhythm and head direction; plants keep growth gesture; architecture keeps skyline and defining openings; objects and vehicles keep functional silhouette and negative shape; landscapes keep one source-specific terrain or spatial relation.
- Keep one principal subject or inseparable relationship. Every base edge, level, path, opening, figure, plant, or environmental fragment must clarify it; never add decorative model-kit scenery merely to fill space.

### Orthographic miniature and paper base

- Use a clean orthographic isometric camera with no photographic perspective distortion. Geometry stays simplified, readable, poetic, and quiet rather than technically over-described.
- Place the subject on one small paper slab, cut-out land piece, low plinth, or source-earned base. Use broad mass contrast, restrained level changes, edge crop, and slight projection to establish scale and solitude.
- Use only a few tiny source-supported details—one figure, railing, tree, opening, track, shadow, or object—when they clarify identity or scale. Never build a complete busy world around the subject.
- Preserve open paper around the model. Reject dense cities, labyrinths, impossible-space tricks, decorative towers, game HUDs, unrelated characters, and copied level designs.

### Fine ink, flat colour, slight shadow, and paper grain

- Use fine, precise, restrained ink lines to define essential edges and construction; keep colour planes flat, matte, and clean.
- Use only slight natural projection and light ambient shadow. Form comes from crisp edges, simplified height, overlap, same-hue steps, and adjacent-colour separation.
- Add subtle paper grain to the ground and colour planes so the piece reads as editorial illustration and paper model, never as noisy vintage print.
- Reject thick comic outlines, airbrushed gradients, bevel noise, metallic sparkle, wet gloss, hard product light, complex PBR, and smooth plastic toy surfaces.

### Source-derived limited colour system

- Extract the photograph's most identifying, atmospheric, and subject-defining colours. Reduce visual noise, purify and soften the colours, and unify them into a limited palette without replacing their source character.
- Preserve the source's warm/cool relationship and emotional colour identity. Use same-hue value steps, neighbouring colours, and only the small colour differences required to distinguish masses and depth.
- Do not impose a fixed pastel family or automatic contrast accent. Every hue must be traceable to the source or to a restrained light/dark derivative of it.
- Keep the result calm, soft, clear, and paper-like. Reject unrelated mint/coral defaults, high-saturation clashes, muddy filters, uncontrolled rainbow, and colourless generic beige.

## Copy and typography belong to 028

028 text is one small thin editorial structure that completes the paper miniature without competing with it—not a headline, slogan, UI label, or data display.

- Automatic copy derives one short title from the visible or supported theme, place, action, state, relation, emotion, or scale tension without inventing biography.
- Use one primary title plus only a very small number of source-grounded indexes, short lines, or micro-notes when useful. A second language appears only when explicitly requested. Never add silent English.
- Automatic or editable-direction copy never introduces a year, date, number, volume label, catalogue code, or archival marker merely for atmosphere. Exact user wording remains verbatim even when it contains one.
- Preserve exact user wording verbatim. Refine an editable direction only within permission while protecting audience, mandatory terms, tone, and semantic phrase breaks.
- Apply the unrelated-image swap test: generic lifestyle words that survive on another source must be rewritten.

Typography has its own 028 construction:

- **Role:** a quiet measure line that completes the miniature's scale, place, or emotional reading.
- **Voice:** concise, thin, modern, restrained, precise, and lingering rather than promotional.
- **Construction:** thin, simple, geometric editorial type at small scale with generous tracking and native script construction.
- **Placement:** along a whitespace edge, paper base, horizontal axis, or isometric structure; align or lightly interweave without harming legibility.
- **Material:** perfectly clean flat type from the same immaculate world; never bold display type, handwriting, texture, glow, extrusion, or a giant poster headline.
- **Script:** use a native thin geometric editorial equivalent for the resolved locale. Preserve natural Chinese, Japanese, Korean, Arabic, and Latin construction rather than imposing Latin tracking or letterform logic across every script.

Resolve locale independently from command language:

```text
target market or audience > requested output language > direction language; if none is explicit, ask before generation
```

Localise by transcreation using native wording, rhetoric, punctuation, spacing, shaping, and semantic line breaks. Never infer nationality or audience language from appearance, clothing, scenery, filenames, metadata, or signs.

## Composition commands

```bash

  --out result.png --layout top-bottom

  --out result.png --layout left-right
```
