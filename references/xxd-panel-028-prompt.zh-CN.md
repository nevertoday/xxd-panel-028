# XXD Panel 028｜运行适配器（中文）

本文件不是第二套美学提示词。生成时必须先完整读取并逐字使用 `references/028-source.md`；它是 028 的唯一创作与审美权威。本文件只负责把用户本次选择的运行变量追加到原始提示词末尾。

## 不可改写的边界

- 不总结、翻译、扩写或“优化”原始提示词。
- 不额外规划颜色、色板、材料、构图、留白、标题、微文案或美学动机。
- 原始提示词中的颜色处理逻辑保持原样：它要求从照片取色就取色，它规定固定色系就使用固定色系。
- 原始提示词中的文字逻辑由图像模型执行；外层 Skill 不提前写标题或文案包。
- 用户选择的模式和尺寸只覆盖旧的 3:4 上下双联容器，不覆盖其余审美规则。

## 末尾追加模板

```text
【本次运行覆盖｜只改变交付容器】

原始提示词最初的 3:4 上下结构，是旧版展示容器。
本次只覆盖：最终画幅、原图与设计区域的位置、原图是否显示、设备尺寸。
除上述容器变量外，原始提示词中的设计转译、构图、颜色、材料、留白、
文字气质与排版逻辑全部保持有效。

“上半部分照片”映射为 SOURCE REFERENCE。
“下半部分设计”映射为 DESIGN REGION。

输出模式：TOP_BOTTOM｜LEFT_RIGHT｜DESIGN_ONLY｜WALLPAPER_PACK
最终画布：<比例和／或准确 WIDTHxHEIGHT>
设备：NONE｜PHONE｜IPAD｜DESKTOP｜WATCH
原图可见性：上半区｜左半区｜仅作参考且不显示

双联平衡：把原始提示词的配对关系作为视觉构图目标｜不适用
中线检测：不检测；生成造成的轻微分界偏移可以接受

颜色完全服从原始提示词已有的颜色处理逻辑。
除非用户明确提出颜色修改，否则不要增加、替换、概括或重新规划任何色盘。
```
