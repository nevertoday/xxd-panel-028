# XXD Panel 028 원본 프롬프트 · 한국어 번역

> 읽기와 공유를 위한 충실한 번역입니다. 실행 시 유일한 기준은 [중국어 간체 원문](zh-CN.md)입니다.

제가 업로드한 각 사진을 각각 독립된 고급 디자인 포스터 한 장으로 제작해 주세요. 여러 이미지를 조합하지 말고, 각 사진을 개별적으로 출력합니다. 전체적으로 3:4 세로 구도를 사용하며, 위아래 두 영역의 높이는 엄격히 1:1로 하여 각각 화면의 50%를 차지합니다.

위쪽 절반에는 원본 사진을 유지하고, 주 피사체의 구조, 사실적인 질감, 자연스러운 빛과 그림자, 원래의 색채 분위기를 보존하며, 약간의 고급 사진 색보정만 적용하여 예술 잡지, 독립 출판물, 전시 사진의 질감을 갖게 합니다. 화면 비율에 맞추기 위해 하늘, 지면 또는 환경 배경을 자연스럽게 확장할 수 있지만, 주 피사체를 늘이거나 왜곡하거나 변경해서는 안 됩니다.

아래쪽 절반에서는 사진에서 가장 식별하기 쉬운 **주 피사체, 윤곽, 자세와 서사적 관계**를 추출하여 종이 위에 진열된 미니어처 입체 모형이나 건축 모형과 같은 정교하고 미니멀한 아이소메트릭 일러스트로 재구성합니다. 사진의 디테일을 기계적으로 복제하지 말고, 개괄적인 덩어리, 선명한 가장자리, 간결한 위계와 미니어처 장면의 관계로 주 피사체를 다시 표현하여 한눈에 알아볼 수 있는 정체성의 특징을 유지하는 동시에 조용하고 절제되며 시적인 편집 일러스트의 분위기를 갖게 합니다.

전체적으로 **아이소메트릭 시점, 미니어처 경관, 종이 모형의 느낌**이라는 구도 논리를 사용합니다. 주 피사체는 잘라내어 작은 종이나 미니어처 받침대 위에 놓인 것처럼 보이게 하고, 주변에는 넓은 여백을 남기며, 부피의 대비, 가장자리 재단, 미세한 투영과 소량의 작은 디테일을 통해 규모감과 고독감을 형성합니다. 주 피사체를 받쳐 주는 보조 요소를 극소량 추가할 수 있지만, 두 번째 시각적 중심을 형성해서는 안 됩니다.

배색은 위쪽 원본 사진에서 전부 추출하며, 가장 식별성이 높고, 가장 분위기 있으며, 주 피사체를 가장 잘 대표하는 색상을 우선 보존한 뒤 복잡한 색채를 **정리하고, 정제하고, 부드럽게 다듬어 제한된 색상 팔레트로 통일**합니다. 원본 이미지의 온도 대비와 색채 개성을 유지하되 잡색과 시각적 노이즈를 줄여 색상이 더 차분하고, 절제되고, 부드러우며, 종이 위 편집 일러스트 같은 느낌이 들게 합니다. 같은 색의 명암, 인접색 관계와 소량의 색상 차이로 덩어리를 구분하며, 원본 이미지와 무관한 고정 색상 계열을 임의로 추가하지 않습니다. 섬세한 잉크 선, 평면적인 색면, 미세한 그림자와 종이 입자로 구조와 층위를 표현합니다.

문자는 구도의 일부로서 영리하게 개입합니다. 사진의 주제, 장소, 동작, 상태 또는 감정에서 사용자가 지정한 목표 언어로 짧은 제목을 추출하고, 극소량의 번호, 짧은 문구 또는 미세 주석을 곁들입니다. 문자는 가늘고, 절제되며, 현대적인 편집 감각을 유지하고, 여백 가장자리, 주 피사체의 받침대, 수평축 또는 아이소메트릭 구조를 따라 배치하여 그래픽과 함께 조용하고 정교한 레이아웃 리듬을 형성합니다.

전체적으로 **미니멀한 아이소메트릭 일러스트, 미니어처 입체 모형, 종이 위의 경관과 고급 편집 디자인**을 참고하여 조용하고, 시적이고, 절제되며, 정교하고, 소장 가치가 느껴지는 시각적 분위기를 구현합니다. 만화 같은 느낌, 고채도 대비색, 원본 이미지와 무관한 고정 배색, 플라스틱 같은 3D 느낌, 복잡한 장면의 누적, 전자상거래 느낌과 템플릿 느낌은 피합니다.
